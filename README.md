# California Housing: множественная линейная регрессия

Учебная работа по регрессии на датасете California Housing (20 640 наблюдений, `sklearn.datasets.fetch_california_housing`). Цель: предсказать медианную стоимость жилья.

## Что сделано
- EDA: размер данных, типы, пропуски, распределения, корреляции
- Множественная линейная регрессия (`scikit-learn`), диагностика модели через `statsmodels` и `scipy.stats`
- Оценка на отложенной выборке

## Результат
На тестовой выборке **R² = 0.576, RMSE = 0.746** (целевая переменная в единицах 100 000 $). Это типичный уровень линейной модели на этом датасете: нелинейные зависимости (например, от координат) она не ловит.
